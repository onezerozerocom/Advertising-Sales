# 광고비와 매출 사이의 관계 알아보기 — 설정 방법

이 폴더에는 파일이 세 개 있습니다.

| 파일 | 어디에 쓰나요 | 학생에게 주거나 깃허브에 올리나요 |
|---|---|---|
| `index.html` | 학생이 여는 학습지 웹앱 (+ 선생님용 학생 결과 보기) | **올립니다** |
| `Code.gs` | 구글 시트에 붙이는 답안 수집 코드 | **올리지 않습니다** (비밀번호와 정답표가 들어 있음) |
| `README.md` | 이 설명서 | 올리지 않아도 됩니다 |

설정은 세 단계입니다. **구글 시트 준비 → 웹앱에 주소 넣기 → 학생에게 나눠 주기.**

---

## 1단계. 구글 시트 준비하기 (약 5분)

1. 구글 드라이브에서 **새 구글 스프레드시트**를 만듭니다. 이름은 자유롭게 정합니다. (예: 광고비와 매출 학습지 결과)
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 모두 지우고 `Code.gs`의 내용을 통째로 붙여 넣습니다.
4. 맨 위의 비밀번호를 바꿉니다.
   ```js
   const TEACHER_PASSWORD = '여기에-비밀번호';
   ```
   학생들이 짐작하기 어려운 값으로 정하세요. 바꾸지 않으면 결과 화면이 열리지 않습니다.
5. 💾 **저장**을 누릅니다.
6. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 톱니바퀴(유형 선택)에서 **웹 앱**을 고릅니다.
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
   - **배포**를 누릅니다.
7. 권한 승인 창이 뜨면 선생님 계정을 고르고 허용합니다.
   "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누르면 됩니다. 선생님이 직접 만든 코드라서 나오는 안내입니다.
8. **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둡니다.

> "모든 사용자"로 해야 로그인하지 않은 학생도 답을 보낼 수 있습니다. 학생은 답을 **보내기만** 할 수 있고, 결과를 보거나 지우려면 비밀번호가 있어야 합니다.

## 2단계. 웹앱에 주소 넣기

`index.html`을 메모장(또는 VS Code)으로 열고 아래 줄을 찾습니다. (Ctrl+F로 `SHEET_URL` 검색)

```js
const SHEET_URL = "";
```

따옴표 사이에 1단계에서 복사한 주소를 붙여 넣고 저장합니다.

```js
const SHEET_URL = "https://script.google.com/macros/s/AKfy...../exec";
```

## 3단계. 학생에게 나눠 주기

둘 중 편한 방법을 고르세요.

**방법 A. 깃허브 페이지로 올리기 (주소 하나로 나눠 주기)**

1. 깃허브에서 새 저장소(repository)를 만듭니다. (Public)
2. **Add file → Upload files**로 `index.html` **하나만** 올리고 Commit 합니다.
3. 저장소의 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 Save 합니다.
4. 1~2분 뒤 위쪽에 나오는 주소가 웹앱 주소입니다.

**방법 B. 파일로 나눠 주기**

`index.html` 파일을 학생 컴퓨터에 복사해 크롬이나 엣지로 엽니다. 인터넷이 연결되어 있으면 제출도 됩니다.

| 누가 | 주소 |
|---|---|
| 학생 | `https://(아이디).github.io/(저장소이름)/` (방법 B는 `index.html` 파일) |
| 선생님 결과 화면 | 학생 주소 끝에 **`#teacher`**를 붙입니다. 예: `https://(아이디).github.io/(저장소이름)/#teacher` |

---

## 학생은 이렇게 제출합니다

1. 맨 위에 **학번·이름**을 적습니다. 짝꿍과 함께 했다면 **+ 짝꿍 추가**로 최대 3명까지 더 적습니다.
2. STEP 1~5를 풉니다. 적은 내용은 **탭이 열려 있는 동안만** 저장됩니다. 새로고침해도 남아 있지만, 탭이나 브라우저를 닫으면 지워집니다.
3. 맨 아래 **선생님께 제출하기**를 누릅니다. "✓ ○시 ○분에 제출했어요."가 뜨면 끝입니다.
4. 제출한 뒤 답을 고치면 "다시 제출해 주세요"가 뜹니다. 다시 누르면 **같은 줄이 최신 답으로 바뀝니다.** (새 줄이 생기지 않습니다)

## 선생님은 이렇게 확인합니다

**학생 결과 보기 (`#teacher`)**

- 비밀번호를 넣으면 제출한 학생 목록이 학번 순으로 나옵니다. 30초마다 새로 불러옵니다.
  - **채점 문항 정답**: `Code.gs`의 정답표(`ANSWER_KEY`)와 비교한 자동 채점 결과
  - **서술 작성**: 서술형 칸을 몇 개 채웠는지 (서술형은 채점하지 않습니다)
- 학생 줄을 누르면 STEP별로 **학생 답 · 정답 · 채점(○/✕)**이 나옵니다.
- **문항별 정답률**을 펼치면 반 전체가 어느 문항을 많이 틀렸는지 볼 수 있습니다.
- 연습으로 낸 답은 학생 화면의 **이 학생 기록 삭제**로 지웁니다. (두 번 눌러야 지워집니다)
- 다 보면 **잠그기**를 누르세요. 브라우저 창을 닫아도 잠깁니다.

**구글 시트**

같은 내용이 시트의 **학생결과** 탭에 학생 1명(컴퓨터 + 학번) = 1줄로 쌓입니다. 문항마다 열이 따로 있어서 정렬·필터나 엑셀로 내려받기를 바로 할 수 있습니다.

## 정답표 고치기

자동 채점은 `Code.gs` 위쪽의 `ANSWER_KEY`를 기준으로 합니다. 정답은 학생 웹앱에 들어 있지 않고 **구글 시트 쪽에만** 있어서, 학생이 웹앱 코드를 열어 봐도 정답을 찾을 수 없습니다.

- 숫자는 ±1%(최소 ±0.011)까지 정답으로 봅니다. 예: `r_TV: 0.90`이면 0.89~0.91을 정답으로 처리합니다.
- 글자는 똑같아야 정답입니다. 여러 답을 허용하려면 `bestVar: ['TV', 'tv']`처럼 적습니다.
- 채점하고 싶지 않은 문항은 그 줄을 지우면 됩니다.
- **STEP 4 값(MSE 5.758 등)은 데이터 샘플링을 `70%` + `재현 가능한(결정론적) 샘플링`으로 했을 때의 값입니다.** 설정이 다르면 학생마다 값이 달라지니, 수업 전에 선생님 컴퓨터에서 한 번 확인해 보세요.
- 1-(1) **속성 개수**는 Sales를 포함해 셀지(4) 빼고 셀지(3)에 따라 답이 달라서 정답표에 넣지 않았습니다. 필요하면 `cols: 4`처럼 추가하세요.

고친 뒤에는 아래 **Apps Script 코드를 고쳤을 때**처럼 다시 배포해야 반영됩니다.

## 수업 전에 꼭 해 볼 것

1. 학생 주소를 열고 학번·이름을 넣은 뒤 몇 칸을 채우고 **선생님께 제출하기**를 누릅니다.
2. "✓ 제출했어요"가 뜨는지 봅니다.
3. 구글 시트의 **학생결과** 탭에 한 줄이 생겼는지 봅니다.
4. 선생님 주소(`#teacher`)에서 결과와 채점이 보이는지 봅니다.
5. 확인이 끝나면 그 학생을 눌러 **이 학생 기록 삭제**로 지웁니다.

## 알아 두면 좋은 점

- **한 컴퓨터를 여러 학생이 쓸 때:** 학생이 탭(브라우저)을 닫으면 학습지에 적은 답이 지워지므로, 다음 학생은 빈 학습지로 시작합니다. 시트에는 **컴퓨터 + 학번**마다 한 줄씩 저장되어 앞 학생의 제출 기록을 덮어쓰지 않습니다.
- **제출 전에 창을 닫으면:** 제출하지 않은 답이 있을 때 창을 닫으려 하면 브라우저가 "사이트에서 나가시겠습니까?"처럼 한 번 묻습니다. 그래도 닫으면 답이 사라지니, 수업 끝나기 전에 꼭 제출하게 해 주세요.
- **새 학기/새 반:** 시트의 **학생결과** 탭 이름을 바꾸거나 지우면, 다음 제출부터 새 탭에 쌓입니다.
- **학번·이름 확인:** 학생 로그인이 없어서 학생이 적은 학번·이름을 그대로 저장합니다.
- **Apps Script 코드를 고쳤을 때:** **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**로 다시 배포하면 주소가 그대로 유지됩니다. (새 배포를 만들면 주소가 바뀌니 2단계를 다시 해야 합니다.)
- **SHEET_URL을 넣지 않으면:** 학습지는 그대로 쓸 수 있고, 제출 버튼을 누르면 "아직 선생님이 제출 기능을 연결하지 않았어요"라고만 나옵니다.
