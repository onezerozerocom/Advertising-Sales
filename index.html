STEP4

기계학습 기반 회귀 분석으로 매출 예측하기

TV 광고비로 Sales를 예측하는 단순 선형 회귀 모델을, 이번에는 데이터를 학습 데이터 70%와 평가 데이터 30%로 나누어 만들어 보세요. 모델이 한 번도 보지 못한 데이터를 얼마나 잘 예측하는지 확인하는 것이 기계학습 기반 회귀 분석입니다.

오렌지3에서 이렇게 해 보세요
  1. STEP 3에서 쓴 Select Columns(열 선택)를 다시 열어 Features에 TV만 남긴 뒤, 여기에 Data Sampler(데이터 샘플링)를 연결합니다.
    데이터 샘플링 창에서 데이터의 고정 비율 (Fixed proportion of data)을 70%로 정하고, 옵션의 재현 가능한(결정론적) 샘플링 (Replicable sampling)에 체크합니다. (체크해야 모두 같은 데이터로 나뉘어요.)
  2. Linear Regression(선형회귀)을 하나 더 놓고, 데이터 샘플링과 연결합니다. 선을 더블클릭해 연결선 편집 창에서 샘플 데이터 → 데이터로 이어 줍니다.
  3. Predictions(예측 결과 보기)를 놓고, 선형회귀 (1) → 예측 결과 보기를 연결합니다. (모델 → Predictors)
  4. 데이터 샘플링 → 예측 결과 보기를 연결하고, 연결선 편집 창에서 남은 데이터 (Remaining Data) → 데이터로 이어 줍니다.

    💡 샘플 데이터(70%)는 학습용 → 선형회귀로, 남은 데이터(30%)는 평가용 → 예측 결과 보기로 보내요. 둘이 바뀌면 잘못된 결과가 나와요.

  5. 완성된 위젯 연결은 아래와 같습니다.
  6. Predictions를 열어 행이 60개인지 확인하고, 왼쪽 아래 성능 점수 표시에 체크하면 평가 지표가 나타납니다. 위쪽 표시할 회귀 오류는 차이 (예측값 − 실제값)로 둡니다.
